01 / PIPELINE

Five passes from a sentence to an MP4.

Each stage writes an artifact you can inspect. Nothing is a black box — the trace log, beats table and probe frame are all in the Studio.

  1. STEP 1

    Plan 4-Act Storyboard

    LLM plans hook, mechanism, insight, takeaway.

    → plan.json
  2. STEP 2

    Synthesize Voiceover

    Sarvam AI generates per-act audio and measures its duration.

    → act_1.mp3 · 4.82s
  3. STEP 3

    Generate Time-Synced Code

    LLM writes a self-contained ReelScene Manim class paced to the audio.

    → reel_scene.py
  4. STEP 4

    Render 1080p + Self-Heal

    manim render -qh at 1080×1920. Auto-repairs on error.

    → 1080×1920 · 60fps
  5. STEP 5

    Mux & Deliver

    FFmpeg mixes narration + SFX + video, then streams to your browser.

    → output/job_id.mp4

03 / UNDER THE HOOD

A real render engine, not a template library.

SELF-HEALING

The repair agent reads the traceback, so you don't.

If a Manim script fails, the agent reads the Python traceback and stderr, patches the code and recompiles — up to 3 retries. Jobs rarely fail; when they do, you get a plain-language reason.

unexpected keyword 'tip_len'

PROCEDURAL MIX

Music ducks. Bottom 20% stays clear.

FFmpeg sidechain compression ducks music under voice; SFX hit on scene starts. No text in the bottom 20% — safe for Instagram UI.
